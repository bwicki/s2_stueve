🎈 Quick start
This tool draws a Stüve, Emagram, or Skew-T diagram from Windsond S2 radiosonde ascent data. Load your own CSV, or explore the sample flight. Hover the chart for readings at any height — diagram type, altitude unit, and wind display are adjustable just above it. Export, print, or share a link once you're ready.

Upload to SondeHub (Amateur)
This sends this flight's ascent telemetry to amateur.sondehub.org, where it becomes publicly visible on their live map. SondeHub's own tools are built for near-real-time tracking; uploading a completed flight after the fact works technically but isn't the typical use case — please make sure that's okay before proceeding. The upload uses SondeHub's published API directly from this page; if your browser or network blocks the request (a real possibility, since this isn't the exact workflow SondeHub was designed for), you'll see an error below instead of a silent failure.

This file is a self-contained web application — uploading a CSV locally is enough, no account needed to use it. "Create link": the full dataset is stored via a small shared Cloudflare Worker endpoint, so the link only carries a short reference (works for anyone visiting this page, no login required). If that storage endpoint is unreachable, the button automatically falls back to a self-contained link with the data thinned down and encoded directly in the URL — still shareable, just not full resolution. Reverse-geocoding the launch location and the map's street tiles also need an internet connection; if blocked, coordinates and a schematic flight-path plot are still shown instead.
